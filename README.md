# Планировщик питания

Персональное PWA-приложение для iPhone: меню, планнер, покупки, вес, витамины, вода и спорт. Все данные хранятся локально в IndexedDB. Сервер и регистрация не нужны.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview -- --host
```

Тесты расчётов:

```bash
npm test
```

Откройте адрес из терминала на компьютере. Для iPhone нужен HTTPS или доступ в той же сети через `vite preview --host` / туннель.

## Установка на iPhone

1. Опубликуйте проект по HTTPS, например через GitHub Pages.
2. Откройте ссылку сайта в Safari на iPhone (не во встроенном браузере).
3. Нажмите «Поделиться» → **На экран «Домой»**.
4. На экране появится иконка «Питание».
5. Для уведомлений откройте установленное приложение и нажмите «Разрешить уведомления» в настройках.

На iOS фоновые web-push ограничены: нужен установленный PWA, HTTPS и разрешение после действия пользователя. Пока приложение открыто, напоминания работают внутри него.

### Публикация через GitHub Pages

1. Создайте GitHub-репозиторий и отправьте в него файлы проекта в ветку `main`.
2. В репозитории откройте **Settings → Pages** и выберите источник **GitHub Actions**.
3. Workflow `.github/workflows/deploy-pages.yml` соберёт и опубликует сайт после push в `main`.
4. Откройте выданную GitHub Pages ссылку в Safari и установите приложение на экран «Домой».

Для адреса вида `https://<пользователь>.github.io/<репозиторий>/` базовый путь подставляется автоматически при сборке в GitHub Actions. Manifest и service worker генерируются Vite PWA-плагином во время сборки.

## Импорт Excel

Файл `menu_60_days_1500_kcal.xlsx` в проект не вшит. Импорт: **Настройки → Импортировать Excel**.

1. Выберите лист.
2. Проверьте предпросмотр и сопоставление колонок.
3. Подтвердите импорт. Повтор не создаёт дубликаты блюд с тем же названием.

## Что требует внешней настройки

- **HTTPS / хостинг**, если нужно ставить PWA с интернета, а не с локальной сети.
- **Web Push / APNs** для настоящих фоновых уведомлений на iPhone — отдельный сервис, сейчас не подключён.
- **Синхронизация между устройствами** — архитектура локальная, облако можно добавить позже.
- Иконки приложения находятся в `public/icons/` и `public/apple-touch-icon.png`.
